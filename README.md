### 如何啟用 GitHub Pages
1. 進入此倉庫設定：[Settings](https://github.com/cses87241/triangle-interior-angle-sum/settings/pages)
2. 在 **Pages** 區塊，Source 選擇 **Deploy from a branch**
3. Branch 選擇 **main**，資料夾選擇 **/(root)**
4. 按 **Save**

等待約1分鐘，網址即可使用。

## 內容概要

三個內角的和始終是 **180°**。
